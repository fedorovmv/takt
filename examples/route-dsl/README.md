# Route DSL example

Пример использует `mock` assistant, поэтому запускается без LLM и внешних программ. Его задача — показать полный управляющий контур:

```text
Markdown command
→ agent node
→ loop_group
→ bash validation
→ approval
→ resume отдельной командой
```

Записи `pi` и `opencode` в `config.yaml` являются шаблонами process-адаптеров. Перед реальным применением нужно уточнить CLI-флаги, формат вывода, режим продолжения сессии и политику интерактивных запросов для установленной версии агента.
