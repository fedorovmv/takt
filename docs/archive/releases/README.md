# Исторические release notes

Здесь хранятся versioned alpha-срезы `v0.1.x`, которые раньше находились в
корне `docs`. Они объясняют происхождение решений и сохраняются для
traceability, но не являются текущей спецификацией.

Для текущего поведения используйте [индекс документации](../../README.md),
[`docs/04-architecture.md`](../../04-architecture.md), спецификацию и schemas.
Состояние проекта находится в [`docs/05-implementation-status.md`](../../05-implementation-status.md),
а пользовательский маршрут — в [`docs/user-guide.md`](../../user-guide.md).
